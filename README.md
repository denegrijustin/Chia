# Chia
Four virtual terracotta portrait Chia Pets: plant, water, shade, feed, trim and regrow. Quick mode reaches the first full coat in approximately 2 minutes; slow mode takes approximately 2 hours. Growth continues through twenty-five stages to an outward-bending canopy. Includes separate pet saves, realistic photographic sprouts, virtual sprout varieties, a care journal, tap-to-greet animation, and PNG photo export. Responsive, keyboard accessible, respects reduced motion, optional synthesized sound, and browser-local saved progress. Built with plain HTML/CSS/JS and SVG; no build step.

Deploy: `npm install && npm run deploy`. Cloudflare Worker `chia`, custom domain `chia.elskatemm.com`. Tests: `npm test`.

State and care economy live in `public/model.js`; saves are versioned and sanitized. This is a playful virtual garden, not real-world horticultural advice. No account or cross-device synchronization.

Untrimmed plants keep growing beyond stage 25 while watered. Photographic growth covers the upper scalp and front planting surface; mature stems hang down from roots above. The face remains fixed while the canopy elongates.
